Jawra je samostatná podnikateľská entita zameraná na 3D tlač na zákazku a vlastné modely.
Na sieti **Forge** vystupuje ako uzol **NODE-001**.

Tento repozitár obsahuje výhradne verejný profil uzla podľa štandardu profilu uzla siete Forge:

- [`PROFILE.md`](PROFILE.md) — profil uzla (identifikácia, kapacita, materiály, ponuka, cenník ako štruktúra, lehoty, kontakt, stav dostupnosti)

Kód, katalóg a prevádzkové postupy uzla sa vedú mimo tohto repozitára.
